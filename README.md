# E-Commerce Sales Analysis

## 📌 Project Overview

This project analyzes e-commerce sales data using Microsoft Excel and MySQL.

The objective is to understand sales performance, profitability, customer behavior, product performance, state-wise performance, payment methods, and monthly sales trends.

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- phpMyAdmin
- GitHub

## 📊 Dataset

- Total Records: 5,000
- Date Range: January 2025 – August 2026
- Categories: Electronics, Furniture, Clothing, Grocery
- Data includes:
  - Order ID
  - Order Date
  - Customer Name
  - Category
  - Product
  - City
  - State
  - Quantity
  - Sales
  - Discount
  - Profit
  - Payment Mode

## 🔍 Analysis Performed

### Excel Analysis

- Data cleaning
- Duplicate checking
- KPI calculation
- Category-wise sales and profit
- State-wise sales and profit
- Monthly sales trend
- Top 10 products
- Payment mode analysis
- Charts and PivotTables

### SQL Analysis

- Data validation
- Sales analysis
- Profit analysis
- Category analysis
- State analysis
- Product analysis
- Customer analysis
- Payment mode analysis
- Monthly trend analysis
- Discount analysis
- Profit margin analysis

## 💡 Key Insights

- Electronics generated the highest sales and profit among categories.
- Uttar Pradesh generated the highest sales among states.
- Monitor was the top product by sales.
- Wallet was the highest-sales payment mode.
